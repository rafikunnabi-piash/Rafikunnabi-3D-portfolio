## 🎧 Micro-Interactions & Sensory Craft

* **Web Audio API Synthesizer:** Zero external audio files; pure procedural sound synthesizer providing gentle hover ticks, chime notifications, and ambient feedback (toggleable via the navigation bar).
* **Magnetic Custom Cursor:** Fluid lerping cursor displaying contextual hints (`VIEW`, `EXPLORE`, `INSPECT`, `TIMELINE`, `MAIL`).
* **Adaptive Performance:** WebGL context capped at 2.0 device pixel ratio, with `ResizeObserver` listener, automatic memory disposal on component unmount, and reduced-motion fallback.

## 🛠️ Tech Stack

* **Framework:** React 19 + TypeScript
* **3D Graphics:** Three.js (WebGLRenderer, custom geometries, materials, lighting)
* **Styling:** Tailwind CSS v4 + Custom Modern Typography (`Syne`, `Plus Jakarta Sans`, `JetBrains Mono`)
* **Icons:** Lucide React
* **Audio:** Web Audio API Procedural Synth
* **Build Tool:** Vite 6
